Start with one number

A solar generator is sized by watt-hours (Wh), the energy it stores. A watt-hour is one watt used for one hour, so a 50-watt fan running 8 hours uses 400 Wh. Add up what you use in a day and you know the size you need.

Common questions

What is a solar generator?

A portable battery with wall outlets, USB ports and a 12-volt socket built in, paired with folding solar panels to recharge it. It makes no fumes and almost no noise, so it can be used indoors.

What size do I need?

Phones and lights need about 300 Wh. A CPAP or a 12-volt cooler for a weekend needs about 1,000 Wh. A fridge, Wi-Fi and lights through a one-day outage need about 2,000 to 3,000 Wh.
